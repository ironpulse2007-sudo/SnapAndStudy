# Snap & Study

Snap & Study is an AI-powered study assistant that helps students understand questions, textbook pages, diagrams, and notes in simple language.

## Features
- Ask study questions using text
- Upload textbook pages, questions, diagrams, or notes
- Get simple AI-powered explanations
- Student-friendly Streamlit interface
- Gemini-powered responses

## How to Run Locally
1. Install packages: pip install -r requirements.txt
2. Add GEMINI_API_KEY to .streamlit/secrets.toml
3. Run: streamlit run app.py
